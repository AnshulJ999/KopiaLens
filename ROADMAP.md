# Roadmap

Have an idea or a feature request? [Open an issue](https://github.com/AnshulJ999/KopiaLens/issues/new/choose) or tell me on [Discord](https://discord.gg/22EU4cqEf6).

## Planned

- **Disaster recovery planning.** When a drive dies, one plan to restore everything from every backup (including Backblaze Personal), plus a list of what was never backed up.
- **Excluded Disk Index.** A built-in index of your disks, so the Excluded view shows what isn't backed up on every platform.
- **Smart Backups.** Ready-made backups for common setups, with exclusion lists that leave out the junk most people never need.
- **Dashboard v2.** One home view for all your backups: every Kopia repository and Backblaze together.
- **Smart Tools.** More smart features across the app that find and fix backup problems for you.
- **Better AI agent integrations.** An MCP server, a published setup skill and finer token permissions, so AI assistants can work with KopiaLens out of the box.
- **Server mode.** KopiaLens runs a Kopia repository server, so other computers running Kopia or KopiaLens connect to it with their own logins, without holding the storage's credentials.
