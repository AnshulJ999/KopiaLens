KopiaLens checks for a newer version once a day. Usage stats tell us how many people use it and which features matter. With both off, nothing is sent unless you click Check now.

Anonymous usage stats

Adds a random install id, Free or Pro, how many repositories and which storage types, and the names of features used. Never paths, file names, sizes or anything from your backups.
