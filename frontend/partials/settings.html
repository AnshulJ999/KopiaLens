Kopia indexing

Reads new snapshots so the numbers stay current. It runs separately, one repository at a time, so KopiaLens stays light, and catches up if the PC was off. Backblaze has its own schedule.

Pause indexing

Automatic indexing waits until the pause ends or KopiaLens restarts. Starting an index yourself still works.

Dashboard numbers

Files on disk
Disk lookup

How KopiaLens reads what is on disk: the Excluded browser, rule Preview and space freed by maintenance. Automatic uses Everything when it is running, otherwise a folder scan.

Folder scan time limit {{ duration('diskScanBudget', 'disk_scan_budget', 1) }}

A scan that takes longer answers "not measured" instead of making you wait.

Everything (es.exe) path

Everything is a free Windows file index by voidtools (voidtools.com). es.exe is its command-line tool; Everything itself must be running.

Excluded-folder tolerance

In the Excluded browser a folder counts as backed up when less than this share of it is excluded. Cuts "partial" noise.

Indexing
Memory limit restart

The most memory each repository's index can use, in the app and while indexing. Automatic is based on this PC's memory.

Indexing time limit {{ duration('indexWorkerTimeout', 'index_worker_timeout', 600) }}

An indexing run that takes longer is stopped. The next run continues where it left off.

First index time limit {{ duration('indexFirstTimeout', 'index_first_timeout', 600) }}

The same limit for a repository's first index, which reads every snapshot. Time the computer sleeps doesn't count.

Give up on an unreachable repository after {{ duration('indexWaitUnreachable', 'index_wait_unreachable', 60) }}

A drive unplugged or a cloud store offline mid-index. The run stops, keeps its progress, and the next repository can index.

Stop an index that makes no progress after {{ duration('indexStallTimeout', 'index_stall_timeout') }}

Slow is fine; no progress at all for this long means stuck. 0 turns it off.

Update the index after deletes {{ duration('reindexAfterDeleteDelay', 'reindex_after_delete_delay') }}

How long after the last delete. Back-to-back deletes share one update.

Most files in one delete plan

A bigger match is planned for its biggest files first.

Retry after a failed run {{ duration('indexRetryDelay', 'index_retry_delay', 60) }}

How long to wait before trying a failed indexing run again.

Retries per scheduled slot

0 means a failed run waits for the next scheduled one.

When quitting KopiaLens

Restart always lets indexing finish. A stopped run is tried again later.

Folder reclaimable space ahead of time {{ duration('folderPrewarmBudget', 'folder_prewarm_budget') }}

Nightly time limit for working out folder sizes ahead of time, biggest folders first. Folders it doesn't reach are worked out when you open them. 0 turns it off.

Quiet period after startup restart {{ duration('startupDelay', 'startup_delay') }}

How long after launch before background work starts, so starting the PC isn't followed by a burst of disk and CPU.

Gap between background runs {{ duration('reindexInterval', 'reindex_interval', 300) }}

With indexing set to every N hours: the least time between two runs, also right after a restart.

Ranked files

How many of the biggest files are ranked exactly each night, for Search's Stored and Reclaimable sorting. More takes a little longer.

Listing backend restart

How KopiaLens asks kopia for snapshot listings. The default only runs kopia when something needs it.

App
Debug log

Writes detailed diagnostics to data/logs/kopialens-debug.log, alongside the normal app log. Useful when troubleshooting; leave it off otherwise. Applies immediately.

Local control port restart

Lets scripts on this computer restart or quit KopiaLens through the tray. Nothing else can reach it. Turn it off if nothing uses it.

Ports restart

Change them if another program uses 7123 or 7124, or to run a second KopiaLens. They apply after you quit and reopen KopiaLens; a bookmark or reverse proxy then needs the new port.

Log cleanup

Removes old job, dry-run and mount logs from data/logs/jobs. The newest 100 are always kept.

Task history

How long finished backups and maintenance stay in the Tasks tab.

When another app stops running backups

For repositories where you chose KopiaLens to run backups.

Backblaze updates

Backblaze data folder restart

Where the Backblaze client keeps its file lists. Empty finds it automatically. Read-only - KopiaLens never writes here.

Reindex minimum gap
