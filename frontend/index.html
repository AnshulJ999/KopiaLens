Listing backend
                  

                
Subprocess means zero background kopia activity. Server runs a persistent kopia server in the background. Needs a restart to switch.

              

              

                
Everything (es.exe) path
                  

                
The CLI the Excluded browser uses to list what is on disk. Needs a restart after changing.

              

              

                
Excluded-folder tolerance
                  

                
In the Excluded browser a folder counts as backed up when less than this fraction of it is excluded. Cuts "partial" noise.

              

            


            

              

                
Heavy pass
                  

                
Run at
                  

                
Every
                  

                
Indexing, snapshot analysis, reclaimable, the dashboard rebuild, folder pre-compute and the Backblaze rescan all run together in a separate process that exits afterwards, so this app never holds on to the memory. One repo at a time. If the PC was off at the scheduled time it catches up at the next opportunity. The repo being indexed is briefly unavailable; the others are not.

              

              

                
Dashboard numbers
                  

                
The physical / freeable / dedup columns take about 80 seconds to recompute. Nightly keeps that out of your day; the ↻ Refresh button rebuilds them on demand either way.

              

              

                
Full rebuild
                  

                
Re-walks every snapshot in this repo from scratch instead of only what changed. Rarely needed; takes far longer than a normal pass.

              

            


            

              

                
Background warm pass
                  

                
The cheap in-process pass: next-snapshot times, repository stats and the search landing page. Everything expensive now rides with the heavy pass instead.

              

              

                
Dashboard auto-refresh
                  

                
How often an open Dashboard re-fetches the cached numbers. Cheap: just a re-render when something changed.

              

              

                
Dashboard rebuild interval
                  

                
Only used when Dashboard numbers is set to "Also rebuild during the day". Ignored otherwise.

              

            


            

              

                
Auto-compact DuckDB
                  

                
DuckDB never reclaims space on its own, so the file grows until it is rewritten. Compaction rewrites it; no kopia re-walk is involved.

Heavy-pass hard timeout
                

                  
                  seconds
                

              

                
Handover drain timeout
                  

                    
                    seconds
                  

                
How long the handover waits for queries already in flight before it takes the database offline. Ordinary queries here can run tens of seconds, so do not set this low.

              

              
Retry delay after a failed pass
                

                  
                  seconds
                

              

                
Retries per scheduled slot
                  

                
0 means a failed pass waits for tomorrow's slot.

              

              

                
Folder pre-compute budget
                  

                    
                    seconds
                  

                
Wall-clock cap on the nightly stage that pre-computes folder reclaim, biggest folders first. Anything it does not reach is computed when you open it. 0 disables the stage (it never means "no limit"). The depths it works at follow the Churn tab and bloat-finder depths automatically.

              

              

                
Refcount write interval
                  

                    
                    seconds
                  

                
How often the global content refcount table is rewritten to disk. Rewriting it is a large churn on the database file, so it is deliberately infrequent.

              

              

                
Minimum gap between background cycles
                  

                    
                    seconds
                  

                
Used to size the quiet period after a restart, so restarting soon after a completed cycle does not immediately run another one.

              

              

                
Quiet period after startup restart
                  

                    
                    seconds
                  

                
How long after launch before any background work starts, so booting the PC is not immediately followed by a burst of disk and CPU.

              

              

                
Directory cache budget restart
                  

                    
                    MB
                  

                
Memory ceiling for the in-process directory cache, the single largest resident cost in this app. Anything evicted falls back to the on-disk cache, never to kopia.

              

            


          

        


        

          
Scheduling and interval changes apply within a minute. Items marked restart need one.
