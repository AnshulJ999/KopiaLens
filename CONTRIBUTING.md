# Contributing to KopiaLens

Thanks for helping. KopiaLens is built by one developer, so the best way to start is with an issue.

## Bugs and ideas

- **Bugs:** open an [issue](../../issues/new/choose) with what you did, what you expected, and what happened. An attached diagnostics bundle helps the most (Click the `?` icon in the app).
- **Ideas and questions:** an issue, or the [Discord](https://discord.gg/22EU4cqEf6).
- **Security problems:** please don't open a public issue; see [SECURITY.md](SECURITY.md).

## Pull requests

- For anything bigger than a small fix, open an issue first so we can agree on the shape before you write code.
- Keep each pull request to one change, with tests where the change can break something.
- [BUILDING.md](BUILDING.md) covers running KopiaLens and its tests from source.

## Contributor License Agreement

Before your first pull request can be merged, you'll be asked to sign the [Contributor License Agreement](CLA.md). A bot asks on the pull request; signing takes one click and covers all your future contributions.

The agreement lets KopiaLens keep offering its code under more than one licence (the AGPL here, and commercial terms for organisations that need them) without asking every contributor again. You keep the copyright to your work.
