# Tables

Most lists in KopiaLens are tables you can arrange: which columns show, their order and width, how they line up and how dates read. KopiaLens remembers each table's layout on the server, so it follows you between browsers.

## Arrange columns

- **Move a column:** drag its header.
- **Resize a column:** drag the edge of its header.
- **Sort:** select a column header. Select it again to reverse the order.

## The column menu

Right-click any column header for these choices:

| Choice | What it does |
|---|---|
| **Align** | **Table default**, **Auto**, **Left**, **Centre** or **Right** for this column. **Auto** puts numbers on the right and text on the left |
| **Times** | Only on date columns: **Default (header button)**, **How long ago** or **Date** for this column |
| **Size to fit** | Fits this column's width to its contents |
| **Size all to fit** | Fits every column's width to its contents |
| **Pin to left** | Keeps the column on screen when the table scrolls sideways. **Unpin** releases it |
| **Columns** | Shows or hides columns |
| **Table layout…** | The choices for the whole table (below) |
| **Reset layout** | Puts this table's columns, widths, order and choices back as they were |

## Table layout

**Table layout…** in the column menu, or in a tab's **…** menu, sets choices for one table:

- **Alignment** sets how this table's columns line up, unless a column has its own choice.
- **Width:** **Fill the width** stretches the columns across the window. **Fit to contents** keeps each column as wide as its contents.
- **Reset this table** puts the whole table back as it was.

To set the alignment every table starts from, use **Table alignment** in **Settings → Appearance**. A table's own alignment, and then a column's, win over it.

## How times read

The time button in the header switches every date column between how long ago and the date. A column set to **How long ago** or **Date** in its **Times** menu keeps that choice whatever the button shows.

To see which columns keep their own choice, right-click the time button. **Use this button's choice everywhere** clears them all.

## Rows per page

The Dashboard shows every source by default. For a repository with many sources, choose **Rows per page** in the Dashboard's **…** menu: **All**, **25**, **50** or **100**.
